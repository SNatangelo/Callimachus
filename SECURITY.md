# Security Policy

## Reporting a vulnerability

**Do not report vulnerabilities through public GitHub issues.**

Report suspected vulnerabilities privately to [hello@callimachus.science](mailto:hello@callimachus.science).

Include the affected Callimachus version, a brief description of the issue and its potential impact, and steps to reproduce it using synthetic or sanitised data.

**Do not include API keys, private documents, credentials or other sensitive data**, including in logs, screenshots or attachments. Remove or redact them before sending your report.
