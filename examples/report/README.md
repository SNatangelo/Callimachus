# Public example report

`index.html` is a publication copy of the historical Attention Is All You
Need test report. The standalone redactor removed nonessential copied source
text and the original report seal while retaining claim and verdict evidence.
The adjacent `index.html.redaction.json` records the original and public file
hashes, the fields removed, and the sources affected. The original sealed
report is available in the repository revision preceding this replacement.

The historical run parsed Dropout's page range `1929–1958` as the publication
year. The public copy corrects five parsed/display fields to 2014, the year
written at the end of its bibliography entry. These five fields and their
previous values are listed in the manifest. Historical resolver match fields
remain as recorded by the old run; this copy does not claim that the run was
reexecuted or resealed.

This file demonstrates the report interface. Its retained quotations and
attribution still need review before wider republication.
