# Callimachus 2.0.1

Security update: refresh certificate trust data used for HTTPS downloads, bootstrap pip 26.2.2 from a SHA-256-verified wheel before dependency installation, and update setuptools and wheel to patched releases.

## Download Callimachus

Choose the package for your operating system. Dependency source archives below are not needed to install or run Callimachus.

### Windows x64

- **Recommended:** [Installer, Callimachus-Setup.exe](https://github.com/SNatangelo/Callimachus/releases/download/v2.0.1/Callimachus-Setup.exe) ([SHA-256](https://github.com/SNatangelo/Callimachus/releases/download/v2.0.1/Callimachus-Setup.exe.sha256)).
- **Portable:** [Callimachus-windows-x64.zip](https://github.com/SNatangelo/Callimachus/releases/download/v2.0.1/Callimachus-windows-x64.zip) ([SHA-256](https://github.com/SNatangelo/Callimachus/releases/download/v2.0.1/Callimachus-windows-x64.zip.sha256)).

The installer can offer to download and install the official Microsoft Visual C++ runtime if it is missing. The portable ZIP requires that runtime to be installed already.

### Linux x64

- [Callimachus-linux-x64.tar.gz](https://github.com/SNatangelo/Callimachus/releases/download/v2.0.1/Callimachus-linux-x64.tar.gz) ([SHA-256](https://github.com/SNatangelo/Callimachus/releases/download/v2.0.1/Callimachus-linux-x64.tar.gz.sha256)).

### macOS

- **Apple Silicon:** [Callimachus-macos-arm64.tar.gz](https://github.com/SNatangelo/Callimachus/releases/download/v2.0.1/Callimachus-macos-arm64.tar.gz) ([SHA-256](https://github.com/SNatangelo/Callimachus/releases/download/v2.0.1/Callimachus-macos-arm64.tar.gz.sha256)).
- **Intel:** [Callimachus-macos-x64.tar.gz](https://github.com/SNatangelo/Callimachus/releases/download/v2.0.1/Callimachus-macos-x64.tar.gz) ([SHA-256](https://github.com/SNatangelo/Callimachus/releases/download/v2.0.1/Callimachus-macos-x64.tar.gz.sha256)).

The macOS packages use a persistent local signing identity. They are not signed with an Apple Developer ID or notarized by Apple; macOS may require explicit approval before the first launch.

Extract an entire portable archive before launching Callimachus; moving only the executable breaks its bundled resources. Python is included. Google Chrome is not included and is needed for Guided Fetch browser capture. Configure model credentials locally in Settings; no API keys are included.

Microsoft Store distribution is separate from these GitHub desktop packages.
