# Guida desktop di Callimachus

Questa guida spiega come usare l’app desktop Callimachus per controllare le citazioni in un manoscritto. Apri **Info** nella navigazione principale: la guida è disponibile nella barra laterale di Info. Questa edizione segue l’interfaccia italiana.

Un controllo tipico consiste nello scegliere un manoscritto, configurare e selezionare un modello, avviare l’analisi, esaminare le decisioni in sospeso e consultare il report e la **Cronologia**. Un’analisi completa indica che il flusso selezionato è terminato; non significa che tutte le citazioni supportino le relative affermazioni.
