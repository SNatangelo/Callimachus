# 01 — Quick start

## Open the app

When Callimachus is installed, open it from your operating system’s app launcher or Start menu. Package setup varies by platform and distributor; follow the instructions that came with your desktop app.

The main sections are **Analysis**, **History**, **Library**, **Settings**, **Info**, and **Console**. The guide is in the Info sidebar. Console output is optional; you do not need to type commands for the normal desktop workflow.

## Start a manuscript check

1. Open **Analysis** and drag a manuscript into the drop area, or click it to browse for a file. The picker accepts PDF (.pdf), Word (.docx), LaTeX (.tex), Markdown (.md), plain text (.txt), and HTML (.html).
2. Choose a verification mode and, in Settings and Analysis, configure and select at least one model for Jury 1.
3. Press **Start analysis**.
4. Respond to any Parse review, Guided Fetch, or OCR pause. The app records your decisions and continues when you resume.
5. Read the report when the run finishes. Use **History** to reopen it or continue work later.

If you close a paused run, choose it in History and use **Resume** when available. **Resume latest** continues the latest resumable run from Analysis.

## Before the first online run

Callimachus extracts manuscript text and runs bundled OCR on your computer. Bibliographic searches and source retrieval can contact external services. If Verify uses a remote model, claims and source passages may be sent to that provider. A model running entirely on your computer can keep those prompts local, but it does not make bibliographic retrieval offline. Provider costs and access rules depend on the services you configure.

Read [Privacy and AI](../../legal/en/privacy.md) before starting if the manuscript contains personal, confidential, or sensitive material. See [Analysis](02-analysis.md) for mode choices and what happens when no model is selected.
