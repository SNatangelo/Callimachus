# 05 — Results and History

A report brings together source identity, citation style, evidence availability, and the relationship between each source and its cited claim. These are separate questions: a run can finish while some sources are missing, some references need review, or claims remain unsupported.

## Read the result

Semantic findings may say that a source supports a claim, partially supports it, contradicts it, is related without supporting it, is off topic, or cannot be decided from the available evidence. Negative or uncertain findings are valid results. A **Complete** run means the selected workflow finished; it does not certify that every citation is correct or positively supported.

Check what text was available. Full text gives a broader basis than an abstract, and an abstract or book preview remains a limited evidence scope in the report. A generic web page is not citation evidence. Quoted passages can be checked against the stored source text, but a grounded passage does not guarantee that a model interpreted its meaning correctly. Review important or contested claims yourself.

The report opens when a run completes. From Analysis, use **Open report** when it is available. In History, select a run to open its report, review its outcome, coverage, and completion state, or open the report folder. History loads additional runs as you scroll or choose **Show more**.

## Continue a run without replacing its record

History retains prior runs and their decisions. Use **Resume** for a selected resumable run. To check the claims again with a new Verify attempt, select a completed run and choose **Run Verify again…**. Callimachus creates a new child run; the earlier report and verdicts remain unchanged.

A references-only run contains Parse and Resolve results without Fetch or Verify. Select it in History and choose **Continue with Fetch and Verify** to create a child run that continues with the available source work.

## Export for sharing

**Export** creates a redacted public HTML copy for a completed full analysis. It removes manuscript and source material that is not needed as verdict evidence, while retaining claims, evidence, decisions, and bibliographic information. Inspect the exported file for personal information and publication rights before sharing it. Export saves a file; it does not publish it.
