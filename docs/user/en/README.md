# Callimachus Desktop Guide

This guide explains the Callimachus desktop app for people checking citations in a manuscript. Open **Info** in the main navigation; the desktop guide is available in the Info sidebar. This edition follows the English interface.

A typical check is: choose a manuscript, configure and select a model, start the analysis, review any paused decisions, then read the report and History. A completed run means the selected workflow finished; it does not mean every citation supports its claim.
