# 04 — Reviews and sources

An analysis can pause so you can check how text in the manuscript maps to a reference, or supply a source that automatic retrieval could not obtain. These pauses keep uncertainty visible.

## Review citations and bibliography

The Parse review window appears when there are items that need a decision. You can reopen it from Analysis or History with **Review citations and bibliography**. The window shows the original text and the available candidates.

For each item:

- Match a citation to the reference it actually cites, or leave it unresolved.
- Match a reference only to the claim associated with its citation; this assigns the relationship and does not itself verify that the source supports the claim. Leave an uncertain match unresolved.
- For footnotes, record whether it has no sources or enter separate source strings exactly as they appear.
- Correct a reference title or DOI only when you can confirm the correction. If identity remains ambiguous, keep it ambiguous.

Use **Resume analysis** to save the selected decisions and continue. **Review later** hides the window and leaves the run paused. Unsubmitted selections remain only in the current app session until you resume.

## Use Guided Fetch

When a source needs manual retrieval or identity review, choose **Open Guided Fetch** if that button is available. Select a source to compare its parsed and resolved details, acquired material, and preview.

To provide a source, choose **Full text** or **Abstract**, select or drop the exact file, and use **Confirm source**. Supply an authentic abstract only as an abstract; it cannot be treated as full text. You can open a candidate link in your system browser. **Open in assisted Chrome** is available for browser capture and requires Chrome; automatic retrieval and choosing a local file do not require Chrome.

For an identity decision, use **Confirm: this is the cited work** only after checking the displayed evidence. If you cannot confirm the identity, choose **Keep unverified**. A source whose identity is unresolved remains unavailable for semantic verification.

If a PDF needs OCR, choose **Run OCR** to extract text from that PDF. You can instead choose **Proceed / skip remaining** to continue with available sources. Pending retrievals will be recorded as skipped, unresolved identities will remain unverified, and a PDF without OCR text cannot be assessed from its full text. The files are kept; no missing source text is invented.
